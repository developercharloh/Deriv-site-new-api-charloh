You are a senior quantitative ML engineer, statistical researcher, and Deriv API engineer.

I want you to design and build a production-grade machine-learning research and trading platform for Deriv Synthetic Indices.

OBJECTIVE
=========
Build an ML system that continuously analyzes ALL supported Deriv Synthetic/Volatility Indices and determines which available contract/market currently has the strongest statistically validated probability of satisfying a specified trading condition.

The system must NOT assume that any market is inherently predictable or guarantee profits/win rates. Every claimed edge must be demonstrated through strictly out-of-sample testing and walk-forward validation.

The system should support research and automated execution for these Deriv contract families where available through the current Deriv API:

1. Rise/Fall
2. Higher/Lower
3. Over/Under
4. Matches/Differs
5. Even/Odd where available
6. Only Ups
7. Only Downs
8. Multipliers
9. Accumulators
10. Other Synthetic Index contract types exposed by the current Deriv API

Do NOT hard-code old Deriv symbols, contract names, API fields, or endpoints. First inspect the current official Deriv API documentation and dynamically discover available symbols, contract types, trading parameters, barriers, durations, and payout information.

CORE PRINCIPLE
==============
Do NOT build a simple indicator bot.

Build a machine-learning system that learns relationships between historical market state and FUTURE contract outcomes.

The system must answer questions such as:

- Which Synthetic Index currently has the strongest statistically supported setup?
- Which contract type has the best expected value under the current conditions?
- What is the probability of the selected contract finishing successfully?
- What is the expected payout versus expected loss?
- Is the estimated edge statistically significant?
- Should the system trade or SKIP?
- How does the current market regime compare with historical regimes?

The model must be allowed to say SKIP.

--------------------------------------------------
8. EXPECTED VALUE
--------------------------------------------------

Do NOT select the highest probability contract automatically.

Calculate:

Expected Value =
(P(win) × net_win)
-
(P(loss) × loss)

Account for:

- stake
- payout
- fees
- spread where applicable
- contract pricing
- execution effects
- slippage where applicable

A 70% probability trade with poor payout may be worse than a 60% probability trade with better expected value.
