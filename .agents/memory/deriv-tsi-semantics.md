name: TradingView TSI semantics
description: The intended TSI indicator in Matches and Over/Under, distinct from True Strength Index.
---

For Matches and Over/Under, **TSI** means TradingView's single-line **Trend Strength Index**, period 14, not the two-line True Strength Index. Keep the display and strategy calculation aligned to that indicator; do not add a TSI signal line.

**Why:** The user corrected an earlier configuration after sharing a screenshot; the two indicators have similar names but different calculations and displays.

**How to apply:** Use this meaning anywhere TSI is referenced in the Deriv site unless the user explicitly changes it.
