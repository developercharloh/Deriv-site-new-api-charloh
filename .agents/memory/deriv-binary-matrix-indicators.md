---
name: Binary Matrix MACD and RSI
description: How price indicators qualify Binary Matrix digit contracts
---

Binary Matrix Over/Under entries require the existing digit rule plus both momentum checks: MACD (12/26/9) line above signal and RSI(14) above 50 for Over, or MACD below signal and RSI below 50 for Under. Even/Odd remains governed only by digit rules. Historical qualification, market selection, and the live entry check must use the same indicator conditions.

**Why:** The user approved MACD and RSI as directional filters for Over/Under while preserving the existing digit rules and excluding ROC.

**How to apply:** Keep the indicator periods and directional thresholds aligned across historical and live evaluation. Do not apply price direction to parity contracts or add candle-color conditions unless the Binary Matrix strategy itself introduces them.
